# Graphing Calculator Online

A free online **graphing calculator** for plotting functions, analyzing graphs,
and doing scientific calculations — right in your browser, no install needed.

**Try it live: https://graphingcalculator.online**

## What it does

- **2D function graphing** — plot Cartesian, parametric, and polar functions,
  inequalities, and points with smooth zooming and panning.
- **Expression list** — add expressions, data tables, folders, notes, images,
  and action buttons, like a digital math notebook.
- **Graph analysis** — find roots, maxima/minima, derivatives, integrals,
  tangents, and limits with one click.
- **Sliders & variables** — animate parameters and watch graphs update live.
- **3D surface grapher** — visualize z = f(x, y) surfaces with drag-to-rotate.
- **Scientific calculator** — a full keypad calculator for everyday math.
- **Share graphs** — save and share graphs with a link.
- **AI math assistant** — ask questions about the math you're working on.

## How it works

The calculator runs entirely in your browser: you type expressions such as
`x^2 + 2*x`, `sin(x)`, or parametric pairs, and the graph renders instantly.
Zoom with the mouse wheel, drag to pan, and use the expression list on the
left to manage everything on the graph.

## How to use

1. Open https://graphingcalculator.online
2. Type a function (e.g. `x^2`, `sin(x)`, `sqrt(x)`) in the expression list.
3. Zoom and pan to explore. Click a curve for analysis options.
4. Add tables, sliders, or notes with the **+ Add** button.

## FAQ

**Is it free?**
Yes — the graphing calculator and all its tools are free to use.

**Do I need to install anything?**
No. It runs in any modern browser on desktop, tablet, or phone.

**Can I save or share my graphs?**
Yes — graphs can be saved in the browser and shared via a link.

**What kinds of functions can I plot?**
Cartesian (y = f(x)), parametric, polar, inequalities, and discrete points —
plus data tables and images placed on the coordinate plane.

**Does it work on mobile?**
Yes, with touch zoom/pan and a responsive layout.
